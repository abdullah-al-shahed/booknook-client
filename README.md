# BookNook – Online Library Management System

A feature-rich full-stack web application designed for managing an online library seamlessly. Users can explore books, contribute new titles, borrow books for a specific period, and manage their borrowed history.

## Live Website URL
- **Live Site:** [https://booknook-client-amber.vercel.app/]
## Key Features
1. **Dynamic Catalog & New Arrivals:** Browse through freshly added books with real-time sorting, filtering, and a fully responsive grid UI.
2. **Secure Authentication:** Complete authentication system powered by Better Auth supporting secure session management, login, and registration.
3. **Complete CRUD Operations:** Authenticated users can add new books, update their listings, and remove books from the library inventory.
4. **Smart Borrowing System:** Borrow books with automatic inventory management (decreasing and increasing total copies dynamically) and track active/returned borrows.
5. **Modern UI & Responsive Design:** Clean and interactive user interface built with Next.js App Router, Tailwind CSS, and Shadcn UI components.

## Technologies Used
- **Frontend:** Next.js, React, Tailwind CSS, Shadcn UI, Lucide React, Swiper.js
- **Backend & Database:** Node.js, Express.js, MongoDB
- **Authentication:** Better Auth
